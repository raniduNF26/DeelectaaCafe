# Deelectaa Cafe - Premium Full-Stack Application

Welcome to the **Deelectaa Cafe** digital platform. This repository contains a high-end web application built for a modern, artisanal cafe experience.

## 🚀 Tech Stack

### Frontend
- **React 19** + **TypeScript**
- **Vite** (Build tool)
- **Tailwind CSS v4** (Modern styling)
- **Framer Motion** (Premium animations)
- **React Icons** & **Lucide React**

### Backend
- **Node.js** + **Express**
- **TypeScript**
- **MongoDB** + **Mongoose** (ODM)
- **Dotenv** (Configuration)

## 🛠️ Features

- **Premium Hero Section**: Custom AI-generated visuals with cinematic animations.
- **Dynamic Menu**: Categorized menu system ready for backend integration.
- **Reservation System**: Full booking flow with dedicated backend storage.
- **Artisanal Journal**: Blog system for coffee culture stories and updates.
- **Admin Dashboard**: Centralized management for cafe operations.
- **Mobile Responsive**: Fully optimized for every device size.

## 🏁 Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB (Running locally or via Atlas)

### Setup
1. **Clone the repo**
2. **Setup Backend**:
   ```bash
   cd backend
   npm install
   # Update .env with your MongoDB URI
   npm run dev
   ```
3. **Setup Frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
